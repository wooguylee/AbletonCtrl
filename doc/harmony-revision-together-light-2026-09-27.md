Vocal Guide의 화성 충돌을 실제 토니 MCP로 수정했다. Live 12.4.6, 정지 상태,
128 BPM/4/4/18트랙과 기존 score의 163클립/5,846음표 일치를 먼저 확인했다.

`ableton_update_midi_notes`에 note_id와 pitch만 전달했으며, 삭제/추가/복사나
장치·재생·화면 조작은 하지 않았다. 아래는 MIDI 번호 기준이다.

## 검증

수정 직후 해당 클립을 읽고, 이후 전체 163클립/5,846음표를 다시 조회했다.

- 수정 후 전체 음표가 보완 악보와 일치한다.
- note_id를 포함하여 pitch 외 모든 음표 필드가 수정 전과 동일하다.
- 모든 클립의 시작/끝/이름/색상/음소거가 동일하다.
- 트랙별 장치/파라미터, 음소거/솔로/Arm, 볼륨/팬/센드, Session 슬롯이 동일하다.
- 모든 FX 음과 보완 대상 Guide 구절은 D major 음계 안에 있다.
- 해당 구절과 실제 패드 사이의 직접 반음 중첩(0.05 beat 초과)이 없다.
  이는 모든 종류의 텐션/고조파/이펙트 잔향이 사라졌다는 뜻은 아니다.
- 생성 스크립트의 보완 악보가 실제 MCP 수정 계획과 정확히 일치한다.
- 갱신한 MIDI를 별도로 파싱해 15트랙(메타 1+연주 14), 5,846 note-on 및 대응 note-off,
  128 BPM, 각 트랙 끝 512 beats를 확인했다.

음악 편집은 지원되는 MCP만 사용했다. 실제 오디오 청취·A/B 검증은 하지 않았으며,
MCP에 없는 Set 저장/렌더링과 화면 자동화도 수행하지 않았다.
