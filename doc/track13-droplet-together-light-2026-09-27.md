# 함께 빛으로 — 13번 물방울 음색 (2026-09-27)

사용자는 13번 악기가 전체적으로 어울리지 않아 물방울처럼 청량한 악기로 바꿔 달라고 요청했다.
현재 13번(index 12) `빛 | 드롭 응답 리드`의 Euphoria Lead를 실제 토니 MCP로
**Rubber Bell.adv (Drift/Mallets)**로 교체했다. 설치 브라우저에서 해당 프리셋을 확인했다.

## 적용

- 빠르게 시작하고 짧게 사라지는 벨/플럭 방향으로 Env 1 Attack=.01, Decay=.36,
  Sustain=0, Release=.30을 설정했다.
- Env 2 Attack=.01, Decay=.30, Release=.25로 둥근 음색 변화를 짧게 만들었다.
- Noise On=0, Glide Time=0, Transpose=0, Volume=.45를 설정했다.
- 새 Reverb를 소량 추가했다: Dry/Wet=.16, Predelay=.07, Decay Time=.28, In Lo Cut On=1.
- 기존 Utility의 출력/팬 등은 보존했다. 모든 수치는 native parameter units이며
  초/밀리초/dB로 환산한 값이 아니다. Rubber Bell의 나머지 발진기/변조 특성은 유지했다.

실제 장치 로딩과 파라미터 설정은 MCP로 수행했다. 오디오를 듣거나 렌더하지 않았으므로
물방울 느낌의 최종 청감과 곡 안의 음량 균형은 사용자 청취가 필요하다.

## 검증

설정한 악기 11개/리버브 4개 파라미터를 다시 읽어 대조했다. 13번의 9개 Arrangement
클립/100개 음표 전체가 수정 전과 동일하다. 음표·클립·트랙 이름·믹서 상태를 바꾸지 않았다.
다른 17개 트랙(직전에 교체한 16번 Gentle Sixty 포함), return/master/transport/cue/scenes의
snapshot이 변경 전후 일치했다. 화면 자동화/자동 저장/재생은 하지 않았다.

악기 수정 전 스냅샷·장치 설정, 검증 JSON, 실행 스크립트는 Git 제외
`songs/함께 빛으로/2026-09-25 새 편곡/2026-09-27 13번 물방울 악기/`에 보관했다.
곡 폴더의 현재 악기 목록·최종 snapshot·검증·안내를 갱신했다. MIDI 음표는 동일하므로
기존 MIDI 백업을 유지한다. 초기 생성 스크립트의 Euphoria Lead는 최초 편곡 이력이다.

청취 지점: **34마디 후반(약 1:03)**의 첫 응답, **50마디 후반(약 1:33)**의 벌스 응답.
확인 후 Live Set을 수동 저장한다. 이전 오디오 파일이 있으면 다시 렌더해야 반영된다.
