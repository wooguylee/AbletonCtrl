# 토니로 Arrangement에서 한 곡 만들기

**토니**는 AbletonVVoori / AbletonCtrl MCP의 별명입니다.
사용자는 원하는 음악을 자연어로 설명하고, Codex는 지원되는 도구를 통해 실제 Live
트랙·악기·클립·MIDI 노트를 작성합니다. Control Surface 이름은 AbletonVVoori입니다.

4분 곡의 구체적인 예시는 [K-POP × EDM × CCM 응원가 프롬프트](tony-anthem-prompt.md)에 있습니다.

## 현재 할 수 있는 작업

| 요청 | 토니가 수행하는 작업 |
| --- | --- |
| 드럼·베이스·코드·멜로디 만들기 | MIDI 트랙과 Arrangement 클립 생성, 노트·길이·세기 입력/수정 |
| 곡의 분위기에 맞는 소리 구성 | 설치된 Browser 악기·Drum Kit·이펙트 로딩, 공개된 장치 파라미터 조회/변경 |
| 인트로부터 아웃트로까지 편곡 | 구간별 클립 배치, 같은/다른 트랙 복사·이동, 반복 패턴의 노트 변주 |
| 특정 부분만 수정 | 마디 범위에 해당하는 클립/노트 조회 후 트림·리사이즈·노트 수정 |
| 기존 오디오로 편곡 | 이 PC의 WAV 등 Live가 읽을 수 있는 파일 가져오기와 클립 편집 |
| 구간 정리와 재생 확인 | 트랙/클립 이름·클립 색상, 클립 음소거, 재생 위치·재생/정지 제어 |

템포를 설정할 수 있고, 원하는 조성에 맞는 노트를 작성할 수 있습니다. 장치 로딩은
해당 PC에 설치된 항목을 확인한 뒤 수행합니다. 모든 장치가 모든 파라미터를 노출하거나
모든 음원이 모든 환경에서 열리는 것은 아닙니다.

## 요청에 넣으면 좋은 정보

- **장르·분위기:** 시티팝, 신스팝, 로파이, 하우스 등 / 밝게, 차분하게, 긴장감 있게.
- **속도·길이:** BPM, 박자, 약 몇 분 또는 몇 마디.
- **악기·보컬:** 원하는 악기, 보컬 없는 곡인지, 가져올 보컬 파일이 있는지.
- **구조:** 인트로·벌스·프리코러스·후렴·브레이크·아웃트로와 각 길이.
- **작업 대상:** 사용자가 열어 둔 빈 Set인지, 기존 곡의 어느 구간을 바꿀지.
- **재량:** 정하지 않은 키·코드·악기 선택은 토니가 정해도 되는지.

음악 용어나 마디 수를 모두 정할 필요는 없습니다. 모르는 항목은 "곡 분위기에 맞게
정해줘"라고 요청하면 됩니다. 결과를 들은 뒤 악기와 구간을 지정해서 수정할 수 있습니다.

## 그대로 사용할 수 있는 한 곡 제작 요청

사용자가 새 빈 Live Set을 열어 둔 뒤 아래처럼 요청합니다. 아래 내용은 실행 예시이며,
이 안내 문서를 작성하는 것 자체가 현재 Set을 편집하라는 요청은 아닙니다.

```text
토니를 이용해서 내가 열어 둔 새 빈 Set의 Arrangement에
밝고 따뜻한 시티팝 느낌의 보컬 없는 오리지널 곡을 만들어줘.

- 100 BPM, 4/4박자, A minor를 중심으로 약 3분 정도.
- 드럼, 베이스, 일렉피아노 계열 코드, 패드, 리드 멜로디를 구성해줘.
- 이 PC에 설치된 Live 기본 악기와 이펙트를 사용하고,
  원하는 소리가 없으면 사용 가능한 악기로 대체해줘.
- 인트로 8마디 → 벌스 16마디 → 프리코러스 8마디 → 후렴 16마디
  → 브레이크 8마디 → 마지막 후렴 16마디 → 아웃트로 8마디로 만들어줘.
- 먼저 8마디 핵심 패턴을 만든 뒤 이어서 전체 곡으로 확장해줘.
  같은 패턴만 반복하지 말고 드럼 필인, 베이스 리듬, 멜로디를 변주해줘.
- 후렴에서 악기 수와 리듬의 밀도가 늘어나게 해줘.
- 구간은 클립 이름과 색상으로 구분해줘.
- 연결과 현재 Set의 트랙/클립을 먼저 확인해줘.
  기존 내용이 있으면 보존하고 새 트랙에서 작업해줘.
- 마지막에 실제 클립과 노트를 다시 조회해서 구간 배치·누락을 확인하고,
  내가 들어볼 구간과 저장·내보내기에 필요한 수동 작업을 알려줘.
- 세부 코드 진행과 나머지 음악적 선택은 곡 분위기에 맞게 정해줘.
```

위 구조는 총 **80마디**이며 100 BPM/4박자에서 **3분 12초**입니다.
음악 생성 서비스에서 완성 음원을 받는 방식과 달리, Live 안에 편집 가능한 트랙과
클립을 만들어 곡의 초안을 구성하는 흐름입니다. 음악적 완성도는 청취와 수정으로 다듬습니다.

## 이어서 수정하는 요청 예시

```text
토니, 첫 후렴의 리드가 너무 복잡해. 33~48마디의 리드만
노트 수를 줄이고 2마디짜리 반복 모티프로 바꿔줘. 다른 악기는 유지해줘.
```

```text
토니, 25~32마디 프리코러스는 드럼을 성기게 만들고,
32마디 마지막에 짧은 필인을 넣어서 33마디 후렴으로 연결해줘.
```

```text
토니, D:\Music\vocals\take1.wav를 새 오디오 트랙에 넣고
17마디에서 시작하도록 배치해줘. 기존 악기는 유지해줘.
```

실제 파일 경로와 원하는 마디로 바꿔 요청합니다. 마디 번호는 Live 화면 기준으로 말하면
되며, 내부 beat 좌표 변환은 Codex가 처리합니다. 박자 변경이 있는 곡은 먼저 확인합니다.

## 현재 MCP의 범위

### 곡 파일 저장 위치

생성하거나 작업한 모든 곡은 저장소 루트의 `songs/<곡 제목>/` 아래에 곡별로
보관합니다. `songs/` 전체는 Git에서 제외합니다. Live가 생성하는 Project 폴더와
`.als`, MIDI/오디오 내보내기, 곡 작업 자료도 해당 곡 폴더 안에 둡니다.
프로젝트 지침·대화 요약·검증 기록만 `doc/`에서 관리하고 커밋합니다.

MIDI 파일은 노트 백업이며 Live 악기·이펙트를 포함한 `.als`를 대체하지 않습니다.
현재 MCP에는 `.als` 저장 명령이 없으므로 수동 저장 또는 별도로 허용된 저장 UI
조작이 필요합니다. 곡 제작 요청만으로 화면 자동화를 시작하지 않습니다.
2026-09-25의 화면 자동화 허용은 **이번 곡 저장에만** 해당합니다.

편집 가능한 **곡의 초안과 편곡**을 만드는 데 사용할 수 있습니다. 현재 도구에는
새 Live Set 생성·Set 저장·WAV/MP3 렌더링/내보내기, 노래하는 보컬 생성, 자동 오디오
청취/분석, 트랙 볼륨·팬 전용 setter, 오토메이션 곡선 작성 기능이 없습니다.
장치에 노출된 음량·필터 등의 파라미터 조절과 트랙 믹서 직접 제어는 구분해야 합니다.
재생 명령을 수행했다는 사실만으로 소리를 듣고 음질을 검증했다고 판단하지 않습니다.

새 Set 준비와 마지막 저장/내보내기는 사용자 작업 또는 별도 허용된 UI 작업이 필요합니다.
오디오 파일이 있으면 보컬 트랙을 가져올 수 있지만 보컬 음원 자체를 생성하지는 않습니다.
Locator 추가 생성에는 제한이 있으므로 곡 구간 표시는 클립 이름·색상을 우선 사용합니다.
Warp Off 지연 리사이즈의 Undo 단계, envelope 제한 등은
[타임라인 안내](timeline-editing.md)와 [실기 보고서](live-verification-2026-09-25.md)에 있습니다.
