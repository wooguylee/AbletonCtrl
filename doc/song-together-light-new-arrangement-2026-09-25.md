# 함께 빛으로 — 새 편곡 실기 기록 (2026-09-25)

## 범위와 시작 상태

사용자가 128 BPM, 4/4, D major/B minor, 128마디 오리지널 응원가를 실제 Arrangement에
만들도록 요청했다. 이전 같은 제목의 저장 파일은 보존하고, 이번에는 새로 열린 빈 Set에
작성했다. Live 12.4.6 Suite / AbletonCtrl 0.3.1 연결, 기본 4트랙, Session/Arrangement
클립 없음, 장치 없음, 정지 상태를 MCP로 확인한 뒤 작성했다.

음악 작업은 MCP Python SDK → 실제 stdio MCP → loopback bridge를 통해 수행했다.
화면 자동화와 직접 Live API 호출, 재생/녹음, 자동 저장/오디오 렌더링은 사용하지 않았다.

## 결과

- 기본 빈 트랙 4개 보존, 신규 MIDI 트랙 14개: 총 18트랙.
- Arrangement 163클립, 5,846 MIDI 노트. 이름에 시작/끝 마디와 구간/역할을 표시했다.
- Live 팔레트로 변환된 실제 클립 색상 10종을 재조회했다.
- 처음 작성한 핵심 후렴은 33–40마디: 12클립, 518노트. 이후 나머지 구간을 작성했다.
- 128 BPM × 4/4 × 128마디 = 512 beats = 240초. 모든 클립은 beat 0–512 안에 있다.
- 지정된 10개 구간을 따르며, 긴 구간은 서로 다른 8마디 블록으로 나누었다.
- 후렴의 모든 킥은 정박 4분음표, 스네어/클랩은 2·4박이다. 베이스는 짧은 업비트,
  플럭과 코드 스탭은 서로 다른 8/16분 싱코페이션이다. 스탭은 다음 화음을 반 박 먼저 친다.
- 벌스 2는 림 퍼커션과 응답 리드, 가이드의 선행 진입을 추가했다.
- 두 프리코러스 끝에는 모든 파트가 마지막 반 박 동안 새 음을 내지 않는 MIDI 쉼이 있다.
  이펙트 잔향까지 무음 처리하는 오토메이션은 사용하지 않았다.
- 브리지 89–96마디는 킥과 베이스가 없으며 피아노·패드·가이드·전환 FX로 구성했다.
- 마지막 후렴은 97/105/113마디부터 12→13→14개 레이어: 합창 느낌 패드, 대선율을 추가한다.
- Vocal Guide는 MIDI 62–74(D4–D5) 한 옥타브와 D major 음계 안에 있다. 실제 보컬 음원은 없다.
- 아웃트로는 모티프를 회수하고 D major로 종지한다. 마지막 MIDI note-off는 경계 전에 둔다.

## 설치 확인 후 로딩한 장치

909 Core Kit를 킥, 스네어/클랩, 하이햇/퍼커션의 별도 트랙에 로딩했다.
나머지는 Basic Jupo Bass, E-Piano MKI Mellow, After Glow Pad, Chirp Pluck,
Stereo Saw, Euphoria Lead, Drift(Vocal Guide), Echo Bells, Morning Chorus Pad,
Homebound Lead, Noise Sweep Lead다. Reverb와 Utility를 추가하고 악기별 출력/공간감을 조정했다.
Utility의 값은 normalized native parameter units이며 dB로 환산하지 않았다.

## 검증과 작업 중 보정

모든 트랙의 악기/클립과 모든 클립의 각 음표를 MCP로 다시 읽었다. 원본 악보와 pitch,
start_time, duration, velocity를 오차 0.0001 이내로 대조했다. 클립 시작/끝, 중첩 없음,
음소거 없음, Session 슬롯 비어 있음, 기존 4트랙 보존도 확인했다. 변경한 장치 파라미터를
모두 다시 읽어 설정값과 대조했다. 음색/피크/실제 청감은 자동 검증하지 않았다.

작업용 스크립트의 name 인수 충돌은 빈 트랙 하나가 생성된 시점에 멈췄으며, 상태 확인 후
그 트랙을 재사용했다. Live가 같은 음의 재타건에서 앞 음 길이를 줄이는 native 동작을
악보에도 반영했다. 프리코러스 가이드 6개 음을 D major의 다이어토닉 연결음으로 보정한 뒤
전체 재조회를 반복했다. 핵심 후렴 노트 수를 진행 메시지에서 618개로 잘못 적었으나
실제 기록은 518개이며 후속 메시지에서 정정했다.

표준 MIDI 백업은 tempo/박자/조성/구간 마커와 14개 연주 트랙을 담는다. 별도 파싱으로
5,846 note-on과 대응 note-off, 모든 트랙의 512-beat 끝, 128 BPM을 확인했다.
