- 실제 MCP의 원본/확장 도구와 Arrangement MIDI·warped/unwarped audio 편집을 검증했다.
- Unwarped audio의 다음 tick 길이 갱신에 맞춰 main-thread 지연 실행을 구현했다.
- Undo/Redo 단계 차이와 Locator grid snap의 기존 항목 삭제 위험을 확인하고 보호했다.

- 자세한 사실과 미검증 범위는 ../live-verification-2026-09-25.md를 참고한다.

최종 검증: 실제 MCP 도구 54개/호출 93회 통과, 자동 테스트 61개 통과.
Warp Off 오디오 지연 리사이즈와 MIDI 속성 검사를 수정했으며, Locator 추가 생성 제한과
여러 Undo 단계 가능성을 사용자 안내 및 실기 보고서에 기록했다. 최초 4개 트랙은 불변이다.

작업 요약: 요청 스타일을 구체적인 편곡 지시로 풀어 쓴 복사용 프롬프트를

몽환적인 벌스와 회중이 따라 부르기 쉬운 희망적인 후렴, EDM 드롭, 엇박 악기 역할,
MIDI 보컬 가이드, 현재 MCP 지원 범위와 songs 저장 규칙을 포함했다.
이 작업은 프롬프트 작성이며 실제 Live 조작이나 곡 생성은 수행하지 않았다.

### 대화 요약 — 토니 응원가 「함께 빛으로」

사용자는 장르 조합, 가제, 128마디 구조, 코드 계열, 엇박 역할, 악기 구성, 구간 변주, 검증과 수동 저장 안내까지 정한 뒤 실제 Live Arrangement 완성을 요청했다. 읽기 전용 연결 검사에서 현재 Set이 비어 있음을 확인해 기본 트랙 4개를 보존했다. 토니 MCP로 새 MIDI 트랙과 Live 기본 악기/효과, Arrangement 클립·노트를 생성하고 128 BPM/4/4 및 beat 512 경계를 다시 확인했다. 구간별 MIDI/클립/장치 조회를 수행했고 상세 검증은 `../song-together-light-2026-09-25.md`에 정리했다.

곡 자료와 4행 가사는 Git 제외 `songs/함께 빛으로/`에 저장했다. MCP에 Set Save As나 오디오 렌더 도구가 없어 현재 Set은 아직 미저장이다. 사용자는 Live에서 저장 후 직접 청취·내보내기를 진행한다. 보컬 음성은 생성하지 않았고 FX MIDI 트랙 Arm을 재생 전에 Live에서 끄도록 기록했다.
